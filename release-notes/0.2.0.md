## Ex Libris Bookplate 0.2.0

### 新增

- **豆瓣音乐搜索**：搜索专辑 / 艺术家，勾选后加入书架；类型为 `music`，默认状态 `想听`。
- 豆瓣搜索弹窗新增 **音** 标签，书 / 影·剧 / 音 共用同一套批量加入。
- 音乐封面同样下载大图并带 `Referer`，封面规则与书籍/影视一致。

### 说明

- 音乐搜索读取豆瓣公开搜索页的 `window.__DATA__`（不是官方 API），可能被限流；失败会提示稍后再试。
- 不需要 `obsidian-douban`，也不需要侧车。

### 安装

三件套放到 `<vault>/.obsidian/plugins/ex-libris/`。番茄阅读需可选侧车（手动安装）：

- <https://github.com/Yolkbun/obsidian-ex-libris/releases/tag/sidecar-0.1.0>
- 放到 `<vault>/.obsidian/plugins/ex-libris/bin/fqsidecar.exe`
