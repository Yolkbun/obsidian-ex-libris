## Ex Libris Bookplate 0.1.7

### 新增

- **联动 obsidian-douban（可选）**：设置里可开关；开启时读取 `obsidian-douban` 导入的书影音，关闭时只显示番茄与内建豆瓣搜索添加的条目。
- `CHANGELOG.md`、按版本拆分的 release notes、发布脚本的 notes 校验。

### 改进

- README 重做：banner、徽章、目录、截图墙、豆瓣联动说明。
- 内建豆瓣搜索创建的条目带 `ex_libris: douban-search` 标记，关闭外部联动时仍保留。

### 文档

- 使用指南新增「联动 obsidian-douban」：字段映射、开启/关闭、与内建豆瓣搜索共存与去重建议。

### 安装

三件套放到 `<vault>/.obsidian/plugins/ex-libris/`。番茄阅读需可选侧车（手动安装）：

- <https://github.com/Yolkbun/ex-libris-sidecar/releases/tag/sidecar-0.1.0>
- 放到 `<vault>/.obsidian/plugins/ex-libris/bin/fqsidecar.exe`
