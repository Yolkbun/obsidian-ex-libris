## Ex Libris Bookplate 0.3.0

### 新增

- 番茄阅读器支持**选中批注**：选中文字浮出工具条，可 **高亮**、改 **红/蓝/绿** 字体颜色、**复制**。
- 只有高亮或改色才算“确切编辑”：自动把 **选中文字 + 所在整段** 追加到
  `<书架根目录>/annotations/<书名>/<章序号 - 章名>.md`。
- 批注记录同时写入 `data/annotations.json`，重开章节可恢复高亮/颜色。
- **复制** 与普通阅读不写任何本地文件，仍保持虚拟阅读。
- 右上角 **导出本章** 继续导出整章全文，与批注互不影响。

### 说明

- 批注只支持同一段内选择；跨段落会提示。
- 高亮/改色才写批注；仅选中或复制不会创建笔记。

### 安装

三件套放到 `<vault>/.obsidian/plugins/ex-libris/`。番茄阅读需可选侧车（手动安装）：

- <https://github.com/Yolkbun/ex-libris-sidecar/releases/tag/sidecar-0.1.0>
- 放到 `<vault>/.obsidian/plugins/ex-libris/bin/fqsidecar.exe`
