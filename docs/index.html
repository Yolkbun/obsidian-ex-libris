Installation03

三步，
上架。

Obsidian 社区目录直接安装；也可以手动放三个文件。番茄阅读需要一个可选的本机侧车。

下载

从最新 Release 取 main.js、manifest.json、styles.css。或在 Obsidian 社区插件里搜索 Ex Libris Bookplate。

放入插件目录

把三个文件放进：

<vault>/.obsidian/plugins/ex-libris/

启用并重启

设置 → 第三方插件 → 启用 Ex Libris Bookplate，重启 Obsidian。侧车状态可在设置页检查。

番茄阅读：可选侧车

社区安装器只放三个文件，不会安装侧车。首次运行缺少 fqsidecar.exe 时会弹一次可关闭的引导；插件不会自动下载或更新它。

What it refuses to do04

克制，
也是一种功能。

它不替你登录、不替你搬运、也不替你决定正文该放在哪里。边界写清楚，才知道能不能放心用。

不登录番茄官方书架、收藏、阅读历史需要账号，本项目不碰。书只能手动加。
不主动落盘正文正文只在 cache；导出单章/整本时才写进 vault，且由你指定目录。
不自动装依赖侧车是手动安装的可选组件；插件不下载、不更新、不静默执行它。
Two libraries05

豆瓣与番茄，
各归其位。

豆瓣是“我标记过什么”，番茄是“我正在追什么”。书架把两种时间放在同一面墙上。

DOUBAN · 书 / 影 / 剧

豆瓣

不登录也能搜：公开搜索接口返回书名、作者、年份和封面，选中即建轻笔记。

  • 内建搜索，不需要 obsidian-douban
  • 可选联动：读取 douban 插件导入的 myState / myRating
  • 关闭联动时，内建条目仍保留
联动是只读的：Ex Libris 不会改你的豆瓣笔记，也不回写评分。
FANQIE · 连载

番茄

搜索、目录、正文、书评都在 Obsidian 里；连载更新可在设置里设刷新间隔，或手动刷新当前书目录。

  • 阅读器断点续读，← / → 翻章
  • 摘录带书名、章节与回跳链接
  • 正文默认不进 vault，导出才落盘
番茄正文依赖本机侧车；侧车与插件是分开的两个 release，需手动安装。
FAQ06

先把疑问
摊开。

更完整的安装、字段、侧车与故障排查在 使用指南。

一定要装 obsidian-douban 吗？

不。内建豆瓣搜索可以直接加书/影/剧；obsidian-douban 是可选的联动来源，适合保留你原有的评分和状态。

番茄侧车必须装吗？

只有番茄阅读需要。书架、豆瓣、摘录、进度、导出笔记都不依赖侧车；不装时番茄入口会提示不可用。

为什么社区安装后没有侧车？

Obsidian 安装器只下载三个插件文件。侧车是独立的 exe，需要从 sidecar release 手动下载并放到 bin/；插件不会自动安装。

支持手机吗？

不支持。侧车是 Windows exe，插件标记为 desktop-only；移动端无法运行。

会上传我的笔记或阅读记录吗？

不会。插件没有账号和遥测；豆瓣搜索与番茄请求只发生在你主动搜索/阅读时，正文缓存留在插件目录。

豆瓣搜索提示“访问太频繁”？

豆瓣公开接口会限流，等几分钟再试；这不是插件崩溃。也可以改用 obsidian-douban 联动。
